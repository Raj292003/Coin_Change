To run the python module Coin_Change.py using Python IDLE, follow the below steps
1) Open Python IDLE
2) In the file menu, choose open
3) Browse Coin_Change.py and open it
4) In run menu, choose run module

To run the python module Coin_Change.py using VS code, follow the bellow steps
1) Open Coin_Change.py file in VS code
2) Click on the run python file button in the top right corner
